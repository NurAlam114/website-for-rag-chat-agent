## 📖 Overview

This project is an AI-powered Retrieval-Augmented Generation (RAG) chatbot built using n8n, Google Gemini, Pinecone Vector Database, and Google Drive.

Whenever a new company PDF is uploaded to Google Drive, the workflow automatically processes the document, creates embeddings, stores them in Pinecone, and makes the information available to an AI chatbot on the website.

---

## ✨ Features

- 📄 Automatic PDF ingestion from Google Drive
- 🔄 Google Drive Trigger
- 📥 Automatic PDF download
- 📚 PDF text extraction
- 🧠 Google Gemini Embeddings
- 🌲 Pinecone Vector Database
- 🤖 AI Agent
- 💬 Website Chatbot
- 🧠 Conversation Memory
- ⚡ Real-time document search
